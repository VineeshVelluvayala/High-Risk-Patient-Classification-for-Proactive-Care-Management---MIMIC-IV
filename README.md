# High-Risk Patient Classification for Proactive Care Management Machine learning project predicting hospital resource utilization at admission, using MIMIC-IV v3.1. ## Data Access This project uses MIMIC-IV, a restricted-access dataset. To run this code, you must independently obtain credentialed access via PhysioNet (physionet.org) and complete the required CITI training. Data files are not included in this repository per the MIMIC-IV Data Use Agreement. ## Files - app.py - Streamlit dashboard - [notebook filename] - Data preparation, model training, and evaluation ## Setup 1. Obtain MIMIC-IV data via PhysioNet 2. pip install -r requirements.txt 3. streamlit run app.py
